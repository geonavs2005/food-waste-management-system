MCA Viva Quick Guide: DSA in this Project
14 Algorithms Implemented
This project maps real-world surplus food distribution challenges to classic computer science data structures & algorithms without using Python standard library shortcuts:
Linked List (O(n)) Dynamic inventory storage where food items are inserted and deleted via pointer manipulation.
Queue (FIFO - O(1)) Fair distribution of incoming recipient requests in exact arrival sequence.
Stack (LIFO - O(1)) Audit logs tracking all administrative actions with 1-click Undo capability.
Graph & BFS/DFS (O(V+E)) Logistics network linking Donors, Storage Centers, and Shelters with path exploration.
Greedy Algorithm (O(n log n)) Rapid heuristic allocation solving emergency shortages by prioritizing highest urgency.
Dynamic Programming (O(n*W)) 0/1 Knapsack optimization maximizing total societal benefit under constrained surplus food.
