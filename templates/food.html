Data Structure: Singly Linked List
Insert: O(1) | Search: O(n) | Delete: O(n) | Traverse: O(n)
What is it? A linear collection of data elements called FoodNode whose order is not given by their physical placement in memory; instead, each node points to the next node.
Why are we using it? Allows efficient dynamic insertions and deletions of surplus food batches without requiring contiguous block memory reallocation.
How does it work here? Food items loaded from MySQL are instantiated into FoodNode objects linked sequentially (head -> node1 -> node2 -> ... -> NULL).
